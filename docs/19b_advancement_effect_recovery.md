# 19b. Why did no estimator find the negative effect group?

Generated by `19b_advancement_effect_recovery.py`. Do not edit by hand.

Simulation. `19` reported that every estimator assigned the do not disturb group a positive effect against a true value of -0.1852. This script attributes that result to one of three causes before it is allowed to become a finding.

| Cause | Isolated by |
|---|---|
| A specification | varying the estimator within the observed arm |
| B confounding | the same estimator across observed and randomised arms |
| C information limit | the ceiling arm, true tau regressed on observables |

The randomised arm is a diagnostic dataset built inside this script. Visits are reassigned at random with a fixed seed and the outcome is taken from the matching potential outcome. `18` is untouched and the project pipeline keeps its confounded policy exactly as designed.

## Limitations

The randomised arm is counterfactual and could not be run by any institution without an actual experiment. The ceiling arm consumes ground truth and is not deployable. Both exist to attribute a failure, not to propose a method. All parameters remain illustrative and open in `08_sources.md`.
