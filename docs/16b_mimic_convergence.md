# 16b. Did the logistic fits actually converge?

Generated by `16b_mimic_convergence.py`. Do not edit by hand.

Every logistic fit in `14`, `15` and `16` ran under a filter that suppresses `ConvergenceWarning`. A fit that stopped at the iteration cap would produce the same signature `16` reported: an ordering that transfers alongside a level that does not. This script observes the iteration count directly and refits at five times the budget to see whether the level gap moves.

Regime A only, so every slice is the smaller 321,547 row configuration. Services chosen as the worst case, the largest case and a middling case from `16`.

If no fit hit the cap and the level gap is unchanged at five times the budget, the suppressed warning was never firing and `16` stands. The level failure is a property of the held out population, not of the optimizer. The filter should still be narrowed in the scripts, because a suppressed warning that happens not to have fired is luck rather than design.
