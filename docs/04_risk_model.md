## Reading these numbers

AUC rises with the decision point because later slices carry more behavioural signal. It does not follow that later allocation is better. The addressable population shrinks at exactly the same time: day 0 reaches 100% of withdrawals, day 84 reaches 43.4%. Whether a weaker model applied to everyone beats a stronger model applied to less than half is the question the allocation script answers, and nothing here settles it.
